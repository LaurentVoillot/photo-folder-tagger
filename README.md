# Photo Folder Tagger

Automatic AI-powered photo tagging with XMP sidecar support.
Works with **any photo folder** — no Lightroom dependency required.
Compatible with **Lightroom Classic, Bridge, Capture One, Darktable, DigiKam** and any software that reads XMP sidecars.

> 📖 [Documentation en français](README.fr.md)

---

## Three tagging modes

| Mode | Engine | Speed | Best for |
|------|--------|-------|----------|
| 🌍 **Vacances** | Ollama LLM (qwen2.5vl) | ~1.8 s/photo | Cultural context, place names, travel |
| 🌿 **Balade** | CLIP ViT-B-16 (local) | ~46 ms/photo | Nature walks, landscapes, keywords |
| 🦊 **Animaux** | BioCLIP + CLIP (local) | ~40 ms/photo | Species & subspecies identification |

All three modes write tags into **XMP sidecar files** alongside your photos.
Tags generated by AI are marked with a configurable suffix (`_ai` by default).

---

## Features

- **Drag & drop** folder onto the input field (or click 📂 to browse)
- Three AI engines selectable from the main screen
- Reads, merges and deduplicates existing XMP tags — no overwriting
- Suffix-aware deduplication: `forest` and `forest_ai` are treated as the same tag
- Pause / resume session across launches
- Dark-themed PyQt6 interface with colour-coded log
- Test mode (dry run): preview tags without writing any XMP
- All configuration in a single `config.yaml`

---

## Requirements

- Python 3.10+
- [Ollama](https://ollama.ai) (for Vacances mode only)
- PyTorch + open_clip (for Balade and Animaux modes — Apple Silicon MPS supported)

## Installation

### 1. Clone the repository

```bash
git clone https://github.com/LaurentVoillot/photo-folder-tagger.git
cd photo-folder-tagger
```

### 2. Install Python dependencies

```bash
pip install -r requirements.txt
```

### 3. (Vacances mode only) Install Ollama and pull the model

```bash
# Install Ollama: https://ollama.ai/download
ollama pull qwen2.5vl:7b
```

### 4. Run

```bash
python photo_folder_tagger.py
```

## Usage

1. **Select a folder** — drag & drop it onto the input field, or click 📂
2. **Choose a mode** — Vacances / Balade / Animaux
3. **Start** — click ▶ Démarrer
4. Follow progress in the log panel
5. If interrupted, click **Reprendre session** at next launch to continue

### Test mode

Click **🔍 Test (sans écriture)** to preview generated tags without touching any XMP file.

## Configuration (`config.yaml`)

The single file to edit for tuning models, prompts, and performance.

### Key sections

```yaml
mode: vacances           # Active mode: vacances | balade | animaux

model:                   # Vacances mode — Ollama LLM
  name: qwen2.5vl:7b
  temperature: 0.1
  max_tokens: 80

performance:
  max_image_size: 512    # Pixels (smaller = faster prefill on GPU)
  jpeg_quality: 60
  concurrent_workers: 1  # Keep at 1 — Ollama uses a single GPU thread

xmp:
  tag_suffix: "_ai"      # Appended to every AI-generated tag
  create_if_missing: true
  merge_with_existing: true

clip:                    # Balade mode
  model: ViT-B-16
  pretrained: openai
  top_k: 8
  vocabulary:            # List of candidate tags (zero-shot)
    - rose
    - forêt
    - montagne
    # ...

bioclip:                 # Animaux mode
  confidence_threshold: 0.26
  top_k: 3
  use_context_tags: true
  context_top_k: 5
  ollama_fallback: true  # Falls back to Ollama when score < threshold
```

### Recommended models (Vacances mode)

| Hardware | Model | VRAM |

## Generated XMP structure

For each `IMG_1234.jpg`, a `IMG_1234.xmp` file is created or updated in the same folder:

```xml
<?xpacket begin="﻿" id="W5M0MpCehiHzreSzNTczkc9d"?>
<x:xmpmeta xmlns:x="adobe:ns:meta/">
  <rdf:RDF xmlns:rdf="...">
    <rdf:Description ...>
      <dc:subject>
        <rdf:Bag>
          <rdf:li>forêt_ai</rdf:li>
          <rdf:li>automne_ai</rdf:li>
          <rdf:li>champignon_ai</rdf:li>
        </rdf:Bag>
      </dc:subject>
    </rdf:Description>
  </rdf:RDF>
</x:xmpmeta>
<?xpacket end="w"?>
```

## Troubleshooting

**Ollama unreachable**
```bash
ollama serve
curl http://localhost:11434/api/tags
```

**Model not found**
```bash
ollama list
ollama pull qwen2.5vl:7b
```

**CLIP / BioCLIP not available**
```bash
pip install torch open_clip_torch
```

**XMP not read by Lightroom**
Select photos → *Photo > Read Metadata from File*

**Tags written as `_ai_ai`** (after upgrading from an older version)
```bash
python fix_double_suffix.py /path/to/photos --dry-run   # preview
python fix_double_suffix.py /path/to/photos             # fix
```

**Processing too slow (Vacances mode)**
- Set `max_image_size: 512` in `config.yaml` (default, gives ×6 speed-up vs 1024 px on Apple Silicon)
- Use a smaller model
